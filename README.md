
A Spring Boot REST API demonstrating Singleton, Adapter, Factory, Facade, and Chain of Responsibility patterns.

## Quick start

Requires Java 8. From the project root, run:

```powershell
.\mvnw.cmd clean test
.\mvnw.cmd spring-boot:run
```

See [PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md) for design details, authentication, and API verification instructions. A PDF copy is included as [PROJECT_DOCUMENTATION.pdf](PROJECT_DOCUMENTATION.pdf);
